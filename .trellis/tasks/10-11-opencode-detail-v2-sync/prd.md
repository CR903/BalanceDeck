# opencode 详情页优化：新版官网数据对齐与用量视图重构

## Goal

对齐新版 opencode 控制台的数据与接口，让详情页的**用量窗口、每模型明细、用量趋势**三者口径一致、随窗口联动；补齐 5 小时窗口的模型用量与配额展示；并产出一份「官网还能拿什么数据」的调研报告供讨论。

## Background

官网控制台已改版：`go/status` 响应变胖（每个 meter 新增 `startsAt`），新增 `usage/cost-by-day`（支持 `bucket=hour|day` 与 `since`），鉴权路径不变。详见 `research/console-api-v2.md`。现有实现仍只消费旧字段，且趋势区用的是**本机**历史，与官方窗口脱节。

## Requirements

### R1 用量窗口 ⇄ 明细同步一致

- 窗口边界改用官方 `go/status` 的 `meters.{fiveHour,week,month}.startsAt/resetsAt`（权威），不再用 `resetAt - WINDOW_SPANS` 反推。
- 每个窗口的模型明细改用 `usage/models?since=<该窗口 startsAt>`，保证「百分比/金额」与「模型明细」落在**同一窗口**。
- 三窗口（含 5 小时）都要有明细，不再出现「5 小时窗口没有模型表」。

### R2 用量趋势随左侧窗口联动

- 去掉趋势区右侧的「7 天 / 30 天」切换。
- 趋势与底部记录跟随左侧窗口（5 小时 / 本周 / 本月）：
  - **5 小时**：当前 5 小时滚动周期内，**每小时**的用量节点。
  - **本周**：本周窗口起止内，**每天**的用量节点。
  - **本月**：本月窗口起止内，**每天**的用量节点。
- 底部表格的时间节点列与用量列随筛选动态变化（小时 / 日期）。
- 数据优先取官方 `usage/cost-by-day?bucket=…&since=<window.startsAt>`；官方不可达时退回本机历史并显式标注「本机估算」。
- 图形形态：**窗口驱动的序列视图**（日桶=纵向柱、小时桶=等宽列），不再是日历热力图；与底部记录表口径统一。

### R3 5 小时窗口补模型用量与配额详情

- 5 小时窗口展示：窗口级 `used / limit / percent / 剩余 / 重置`。
- 展示该窗口内**每模型用量**（`usage/models?range=24h&since=<5h startsAt>`）与 token/请求数。
- 每模型**配额**：接口不提供 → 不显示假值，必要时以「—」或缺省呈现，并在文案上不暗示「每模型有独立配额」。

### R4 官网可用数据调研报告

- 产出 `research/console-api-v2.md`（已产出）并在会话中给出结论摘要，供决定后续是否接入按用户、模型定价等。

### R5 接入余额 / 额外额度（本轮）

- 详情页展示 `GET /api/billing/status` 的 `availableMicroCents`（Go 之外可用的额外额度）与 `balanceMicroCents`。
- 官方不可达时**不显示**该区块（不伪造），不劣于现状。
- 只做只读展示，不做充值/自动续费交互。

## Constraints

- 不改凭据路径（Cookie + `x-org-id`）与 base（`/console/api`）。
- 官方不可用时的本机降级与「诚实标注」纪律（ADR-0002）保留。
- 官方接口无 per-model quota：UI 缺省为「—」，不写 0。
- 遵循既有前端结构与样式 token，不引图表库。

## Acceptance Criteria

- [ ] AC1：三窗口边界与官方 `startsAt/resetsAt` 逐秒一致；周窗口为 UTC 自然周（周一 00:00）。
- [ ] AC2：每个窗口（含 5 小时）都能显示该窗口的模型明细，且 Σ明细金额与同窗口口径自洽（不跨窗口串数据）。
- [ ] AC3：趋势区无 7/30 天切换；选「5 小时」显示逐小时节点，选「本周/本月」显示逐日节点，节点范围与窗口起止一致。
- [ ] AC4：底部记录表头/节点列随窗口动态变化（小时↔日期），用量列单位与口径一致。
- [ ] AC5：5 小时窗口可见每模型用量；无 per-model 配额时显示「—」而非 0。
- [ ] AC6：断网/官方接口失败时，趋势退回本机历史并有「本机估算」标注，不静默显示错误数据。
- [ ] AC7：`research/console-api-v2.md` 存在且结论可复现（`scripts/probe-console-live.js`）。
- [ ] AC8：趋势为窗口驱动的序列视图，图形与记录表口径统一（日桶柱状 / 小时桶等宽列）。
- [ ] AC9：详情页展示余额/额外额度；官方不可达时不显示该区块（不显示假值）。

## Out of Scope

- 按用户用量、模型定价展示 —— 待 R4 报告讨论后另立任务。
- 余额的充值/自动续费/支付方式交互（仅只读展示）。
- 改动收集/调度链与快照 schema（除非为实现 R1 必须的最小扩展）。
- 语音/通知/岛上展示逻辑。

## Notes

- 复杂度判断：**复杂任务**，需 `design.md` + `implement.md`。
- 若 R1–R3 与 R4 后续接入方向分歧较大，可拆子任务；当前作为一个任务，R4 为研究交付物。
