# 悬浮球贴边自动隐藏

## Goal

去真人化后收起态只剩 2D 悬浮球（56×56）。当用户把悬浮球拖到屏幕四个边框停靠并停留时，
球体以流体效果被边沿“吸入”（如水滴汇入），只留一枚贴边水渍痕；唤出时流体从水渍汇聚回球形。
球体本身做 3D 观感（渐变高光，无 WebGL），进度环改水满效果（液位 = 百分比）。
减少常驻遮挡，同时不丢失“一点即展开”的仪表盘价值。

## Background（已确认事实）

- 收起态球形态窗口 56×56（`src/shared/pet-view.ts:17` `BALL_VIEW`），主进程按此定窗口尺寸（`src/main/overlay.ts:26-28`）。
- 球体为纯 DOM/SVG（`src/renderer/src/PetBall.tsx:893,902-917`）：56×56 viewBox，r=22 track + fill 圆弧，
  无 WebGL、无 canvas。`isPlan()` 决定套餐画环 / 余额只留素盘（与主卡片同源）。
- 位置持久化 `userData/state.json`，启动/拖拽/显示器变化均夹回工作区（`src/main/overlay.ts:124-126,212-231,252-264`）。
- 拖拽是主进程 16ms 光标轮询 + `setPosition`（`src/main/overlay.ts:327-353`），拖拽中故意宽松夹取（边外 40px/8px），
  松手由 `snapBackToWorkArea` 收回严格区（`src/main/overlay.ts:340-341,355-365`）。贴边隐藏接在 `dragStop` 收回之后。
- 收起态才开光标穿透轮询（90ms，`src/main/overlay.ts:428-447`）；命中区由渲染层上报（`setPetHitbox`）。
  隐藏态下命中判定必须与隐藏偏移同源，否则“看得见点不着”。
- `prefers-reduced-motion` 已是项目惯例，隐藏动画必须有无动画降级。
  已实现的 slide 位移降级为 reduced-motion 路径，流体只走全动效路径。
- ui-ux-pro-max 实测：无“dock auto-hide”直接条目（product 域 0 命中）；liquid-glass（fluid morph，
  a11y 条件：对比度/键盘/可见焦点/reduced-motion）与 biomimetic（SVG morph / canvas generative）为转用指导；
  spring 条目无命中，elastic 缓动为未验证的通用指导（实现时以走查观感为准）。

## Key Decisions（用户已定）

- **触发（2026-10-03）**：拖到边沿 8px 内松手后，窗口在贴边位置停留 1000ms 才隐藏（停留延迟藏，防误触）。
- **唤出（2026-10-03）**：光标在痕迹区停留 300ms 才滑出（停留唤出，防路过抖动）；触屏/无 hover 设备用点击痕迹唤出。
- **开关默认开（2026-10-03）**：设置页 + 右键菜单双入口可关。
- **技术路线（2026-10-04）**：路线 A —— SVG gooey 滤镜 + 渐变 3D 观感，零依赖零 WebGL。
  否决 three.js 真 3D 球：+1.2MB chunk、WebGL 常驻、耗电，与废除真人瘦身方向直接冲突。

## Requirements

- **R1 触发**：仅收起态球形态参与；展开态卡片（384×600）不隐藏。`dragStop` 收回后若窗口边与工作区边距离 ≤ 8px，
  起 1000ms 隐藏计时；期间发生拖拽/展开/光标进入球体/显示器变化则取消。
- **R2 隐藏形态（流体）**：先播吸入合并（窗口不动，球在窗内向贴边侧拉伸成液桥并汇入贴边水渍 pill），
  再整体滑出屏幕外，仅留水渍 pill（沿边沿约 20px × 探出 4px，圆角水滴形）。痕迹区仍可命中。
- **R3 唤出（流体）**：光标进入水渍区停留 300ms（无 hover 设备点击唤出），窗口先滑回贴边全可见位置，
  再播汇聚（pill 拉出液桥、球体回弹成形）。滑出后光标离开球体 1500ms（去抖）且仍在边沿则重新隐藏。
- **R4 四边**：上/下/左/右均支持；以 `workArea` 为贴边基准。角落同时贴两边时取最近一边，
  平局按左/右/上/下顺序确定性选择。macOS 上沿约束见 Risks。
- **R5 动画**：吸入总 ~500ms（拉伸 150ms ease-out → 桥接合并 300ms → pill 定形 + 微回弹），
  汇聚反向 ~400ms；窗口滑出/滑入沿用既有步进（250–350ms / 180–220ms）。
  `prefers-reduced-motion` 下跳过流体与滑动，直接显隐（计时器保留）。
- **R6 持久化**：`state.json` 存 `dock: {edge, hidden}` + 贴边全可见坐标；重启、多显示器断开重连后按当前
  `workArea` 重算隐藏偏移，不漂出可视区。
- **R7 可关闭**：`extras` 开关（`ui:dockHide`，缺省开）+ 设置页“系统”分区 + 球右键原生菜单；
  关闭时取消计时/动画、窗口回到贴边全可见位置并清掉 `dock.hidden`。
- **R8 球体 3D 观感**：径向渐变球体 + 顶部高光 + 底部内阴影，颜色全部取自既有球令牌
  （`--ball-bg` / `--ball-rim` / `--dot-top` / `--dot-bottom`），5 套皮肤各自生效，新增皮肤零代码。
- **R9 水满进度**：仅套餐类（`isPlan()` 为真）启用；球内 clip 圆形 + 双层错速波浪，液位 = 百分比；
  余额类保持素盘。波浪在隐藏态暂停，reduced-motion 下只显示静态液位。

## Acceptance Criteria

- [ ] 球拖到四边松手停留 1s 后播吸入合并，只留水渍 pill 可见（走查截图三帧：拉伸中/桥接中/水渍）
- [ ] 路过水渍不停留不唤出；停留 300ms 播汇聚成球，可点击/拖动/右键；离开 1.5s 后重新隐藏（无来回弹）
- [ ] 液位与百分比一致（单测映射 + 各皮肤走查）；余额类无水满
- [ ] 展开态卡片不触发隐藏；切换展开/收起不残留隐藏偏移
- [ ] `prefers-reduced-motion` 下直接显隐（走 slide/跳变路径），无流体无滑动
- [ ] 重启、显示器拔插后位置/隐藏态恢复且可见
- [ ] `typecheck` + `npm test` + `--uitest` 相关断言绿（含新增隐藏/唤出/取消断言，每条先弄坏验证）

## Out of scope

- 个性人物形态（随废除真人任务下线，不为其做隐藏）
- 展开态卡片的自动隐藏
- idle 超时自动隐藏（非贴边也藏）
- canvas metaballs 流体模拟、three.js 真 3D 球
- 水渍样式定制（发光/形状主题包），保持单一样式

## Risks / Deferred

- macOS 上沿：可见窗口 `setPosition` 到菜单栏上方被系统同步夹回（check 已实测），上沿确定性不藏；
  PRD R4 注记保留，左/右/下三边正常。
- 透明窗口下 SVG gooey 滤镜的合成表现需走查验证（macOS + Windows）；若异常则回退 slide，不阻塞主干。
- goo 滤镜区域裁到 56×56 内，避免全屏 blur 开销；波浪动画隐藏态暂停。
- Windows 缩放/DIP 下 4px 探出过细？走查时在 125%/150% 缩放下复核，不行再调常量。
- deferred（父任务）：国内订阅、皮肤市场、成本追踪、CSV 导出。
