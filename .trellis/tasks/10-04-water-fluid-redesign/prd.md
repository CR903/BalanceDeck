# 水球流体视觉重设计（父任务）

## Goal

收起态 56×56 水球的四项视觉改造，还原用户要的"一球有水、随量变色、会动会吸"的感觉，
同时 5 套皮肤各有自己的球体质感与水效性格。全部走令牌/CSS 变量，新增皮肤零代码。

## 子任务映射

| 子任务 | 交付 |
|---|---|
| `10-04-water-color-by-usage` | 球内水体 + 贴边水柱颜色随用量连续变化 |
| `10-04-pour-in-slosh` | 启动倒水入场 + 荡漾平息动效 |
| `10-04-edge-sip-column` | 贴边吸溜走水 + 屏边温度计水柱（柱内持续动荡） |
| `10-04-skin-fluid-redesign` | 5 皮肤差异化 3D 球体 + 差异化水波 |

子任务可独立验证（各有视觉验收），但实现有顺序依赖：water-color → pour-in →
edge-sip → skin（见 implement.md）。水色是柱水色的同源输入，必须最先。

## 跨子任务验收

- [ ] 4 个子任务各自 AC 全绿
- [ ] `npm run test` 全绿（含同步更新的单测与结构门）
- [ ] `npm run typecheck` 通过
- [ ] 5 皮肤 ×（整球 / 吸入中 / 水柱态）截图走查无方框、无假水位、无糊字
- [ ] reduced-motion 下全部新动效退化为直接显隐（计时器保留）

## 全局约束（所有子任务遵守）

1. 几何/时序/液位唯一口径仍在 `src/shared/fluid.ts`（纯函数，不碰 DOM）；渲染层不自立第二套数（test-structure J2/K 门盯着）。
2. 余额类（非套餐）与算不出比例时不挂假水位、不画假水柱（`showWaves` 纪律延续到柱）。
3. 读数永远 crisp：动效只动 `.petball-goo` 内形状，不碰环外文字层；禁止 outer box-shadow（D6 纪律，窗口贴尺寸）。
4. 等级语义锚点不变：`shared/levels.levelOfPercent` 的 60/85 阈值是唯一真相源；水色连续化只是**表现层插值**，不另立分级。
5. 外部皮肤（`ext:*`）没写新令牌时退化为"统一默认水效 + 无高光/无深度平涂"之上的**合理默认值**，不透明、不错位（延续 `--water-foam/--water-deep` 的 `:root` 兜底纪律）。
