# 端：透明 overlay 窗命中区

透明无边框窗口的点击去留由主进程命中判定，渲染层只报几何。违背即“画得出、点不动”。

## 三纪律

1. **可见交互浮层必并入上报矩形**：确认条/气泡是主体兄弟节点时，只报主体 =
   浮层在命中区外，OS 层直接穿透。可见门（`offsetHeight > 0`）下求并集，平时不加死区。
   （`IslandView.tsx` confirmRef union，照抄 `PetBall.tsx:311-330`。）
2. **量失败必报 fallback，禁止静默早退**：某帧量到 0 就 `return` 会让 hitbox 永久陈旧，
   可见岛永久点穿。量不到报兜底顶条。
3. **dwell 计时与合成输入隔离**：`--uitest` 合成点击动不了真光标，真 `dragStop` 会 arm
   dwell 把岛藏掉致连锁红；回归段用 `setDockHideEnabled(false)` 包夹，测完恢复。

## 视觉高度归因

岛“比原型高”先分层量：布局（DOM）→ 渲染 core（alpha>128）→ 晕（alpha>8）。
本轮布局 52px 逐项一致，+8~12 来自同栈投影 + 辉光呼吸——原型同一套栈，实拍亦然。
结论：压视觉高度动阴影/辉光层，不动本体。
