# 周列日历热力图：三条几何与颜色纪律

适用：把「每天一个值」画成 GitHub 式日历网格（列=周、行=周一..周日）。
来源：2026-10-07 用量热力图（`TrendChart.tsx` + `usageHeatmap.ts`）。

## 1. 日历几何：列的起点是「首日所在周的周一」，不是首日本身

```ts
const first = parseDayKey(days[0].day)
const startMonday = new Date(first.getFullYear(), first.getMonth(), first.getDate() - weekdayMon(first))
col = Math.round((dt.getTime() - startMonday.getTime()) / WEEK)
row = weekdayMon(dt)   // 周一=0 .. 周日=6（JS 的 getDay 是周日=0，要平移一格）
```

**为什么**：首列必须真的是「一周」，跨月的列边界才和月份标签对得上。
对齐留白（首列前面的空格）**不渲染**——它不代表「那天没采到」。

**月份标签只在换月的列出现**：遍历列，取该列第一格，月份变了才标。

实测（2026-09-08..10-07，30 天）→ `cols=5`、`cells=30`、
`marks=[{col:0,'9月'},{col:4,'10月'}]`，每格 `(col,row)` 唯一、row 无越界。

## 2. 空格有两类，只有第二类要渲染成「缺」

| 类型 | 含义 | 处理 |
|---|---|---|
| 对齐留白 | 首列起点周一之前的天，本就不在数据范围 | 不渲染任何节点 |
| 缺样本 | 那天应用没跑 / 采样失败，`lastPct === null` | 不渲染格子，缺口可见 |

**为什么第二类比「填最浅一档」更好**：填成 1 档会把「应用没跑」和「那天用量没涨」
渲成同一个颜色。前者要去查采集为什么停了，后者是正常的休息日——处置完全不同，
不能混。同理 `null` 绝不用 0 补：拿 0 去减会把「没采到」读成「当天涨到 50」。

## 3. 差分与颜色口径（最容易写错的两条）

- **reset 天 `delta = cur`**：用量不会自己下降，`cur < prev` 必是换了周期。
  按 `cur - prev` 算得负数 → streak 断 + 图上是负增量，而实际那天用量很高。
- **强度档是相对的**（标尺 = 本轮 active 窗口的 `maxDelta`），不跨窗口比。
  绝对阈值（如 10pp 一档）会让小额度窗口永远最浅、大窗口永远最深。
- **颜色只用既有 token**：档位用 `color-mix(in srgb, var(--ok) N%, var(--track))` 派生，
  不引入新字面量。外部皮肤改 `--ok` 时热力图自动跟着换，不需要单独配四档。
  空格 = `var(--track)`，1 档必须含 `--ok`，两者一眼可分。

## 4. SVG 别拉伸到 100% 宽

周列网格的宽高比是**竖的**（7/30 天只有 4–6 列 × 7 行）。`width:100%` 会把每格
放大到 40px 以上，失去「一屏看 30 天」的密度。

做法：SVG 上带 `width` / `height` 属性按 1:1 出图（cell 13px / gap 3px，
30 天 = 95×123），CSS 只留 `max-width:100%; height:auto` 在极窄卡上兜底收缩。

## 5. 绝对量与百分比是两份字段，判据必须独立

热力图下方要逐日绝对用量（`used`）时，不要假设「百分比坏 → 绝对量也坏」。官方 API 里
这两者是两份字段，坏一个不必然坏另一个。

```ts
// bucketByDay 里：谁已知谁被保留，另一个保持 null
if (known(p.pct))  { b.lastPct = p.pct; b.maxPct = ... }
if (known(p.used)) { b.lastUsed = p.used; if (p.unit) b.unit = p.unit }
```

**绝对量走同一条 reset 口径**：`used < prevUsed` 必是换周期，delta = cur 而不是负数。
两条口径一旦分叉就会出现「热力图这天最深、明细这天用量是负的」这种自相矛盾的显示。

## 6. JSON 存储加可选字段不需要升 version

磁盘格式从 `{ t, pct }` 扩到 `{ t, pct, used?, unit? }`，**version 保持 1**。

- 加两个可选字段是前向兼容的，老文件读回来就是 `undefined`；
- 升到 version 2 会让本仓的实现把**所有**老文件判成「格式不符」并重建 —— 30 天 × N 供应商
  的历史在一次升级里全灭。
- 代价是升级前那几天绝对量显示「—」。这是可以接受的；**填 0 不可接受**（用户会以为那几天
  真的没花钱，而真实原因是那时还没记绝对量）。

代价要在 PRD 里写明是「明确接受的行为」，否则下一个人会想「怎么会有行显示 —，肯定是个 bug」
然后去「修」它。

## 门禁要钉住什么

`test-usage-heatmap.mjs` 的 G / H 段（结构切片）：

- `lastPct == null` 必须 `return null`（不是渲染最浅档）
- TS 里**不出现** `heat-0`（0 档没有 DOM 节点；出现说明有人把空格渲出来了）
- 差分 / 分档 / streak 必须走纯函数，不能内联口径
- 热力图 CSS 段无 `#xxx` / `rgba()` 字面量，且空格用 `--track`、1 档含 `--ok`

⚠ 负向断言必须带**前置断言**（先确认找得到那一段），否则「那段代码不存在」时会空洞通过。
