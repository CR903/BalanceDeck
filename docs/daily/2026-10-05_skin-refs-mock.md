# 2026-10-05 六参考图转皮肤效果图

## 任务
用户给出 6 张手表表盘参考图（计时橙 / 睡眠极光 / 测速绿 / 心跳红 / 柠檬分段环 / 潮汐水位蓝），
要求按图做出不同效果图，评估是否可做不同皮肤的不同外观。

## 交付
- `prototype/skin-refs.html`（可浏览器打开看 2x 等比效果）+ `prototype/skin-refs.png`（Electron 实拍）
- 6 版：V1 余烬计时橙 / V2 睡眠极光 / V3 极速绿环 / V4 心跳红 / V5 柠檬分段环 / V6 潮汐水位蓝

## 结论（已当面给用户）
- 可做皮肤外观，但 6 套不能全要；推荐 V6（水体保留）/ V3 / V5 / V1，V2 半可用，V4 只做等级态。
- 约束：56px 下刻度圈上限 24 粒、点环每颗 ~5px；环与水双编码二选一；红色撞 danger 语义。

## 坑位
- 原型 HTML 里卡片 2~6 的 stage 闭合行多写了一个 `</div>`，把 card 提前闭合，
  后面卡片全错位。用 Python 按行数 div 配平（`final depth` 归零）一次定位，
  比在 Electron 里猜 DOM 快得多。教训：手写嵌套 HTML 后先跑配平脚本再截图。
- Electron 复跑会读到 localhost:8080 搜索后端错误等无关噪声，截图本身不受影响。
