## 映射（效果图已验证）
- 环弧长度=进度，环弧/水体颜色=等级色（ok/warn/danger），余额统一满格+accent+金额读数。
- V1（dark）：弧色跟等级，41% 用绿（语义优先，身份橙让路）；warn 回橙、danger 红。
- V3（dark 霓虹）：余额=蓝色满环+金额，一眼区分。
- V5（minimal 活力）：进度弧压分段轨道；余额=满格柠檬黄+金额。
- V6（aero）：水高=用量、满水=余额、水色=等级色，零语义改动。

## 修订4（同日）：V6 三段水 morph
- 用户要"球化成浪、浪堆成柱、反向亦然"。V6 demo 重做三段：熔化（晃+水涨顶，450ms）
  → 化浪（球拉散消失 + 行进波带，350ms）→ 堆柱（波注入 + 液面过冲涨 + 浪尖水花 + 回弹，~600ms）；
  唤出反向（泄柱→回浪→凝球，~0.9s）。V3 环版保持原两段。
- WAAPI `fill:forwards` 会压住后续 inline 高度，收尾一律 commitStyles + cancel。
- `morph-mid.png` 为堆柱瞬间定帧（波带注入 + 液面半涨），1050ms 抓拍，无 JS 报错。
- 微瑕：波带在暗底上偏棕（warn 橙 .85），落地时提亮或加发光描边。
